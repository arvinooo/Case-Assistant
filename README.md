# 谈案助手

律师与客户面谈时，边聊边把话转成文字，同时盯着「还缺什么」——缺的那项立刻出提醒，不等模型。

- 转写：**本地 SenseVoice**（sherpa-onnx），录音不出本机，免费
- 提醒：**规则引擎，零延迟**。金额、日期、凭证、不利表述，一出现就出卡片
- 不做：说话人分离、当事人画像、TTS

---

## 启动

```bash
cd voiceapi
ln -sfn /home/arvin/models models          # 模型目录（SenseVoice + silero_vad）
/home/arvin/.venvs/shera/bin/python app.py --port 8787
# 或： ./run.sh
```

浏览器打开 `http://127.0.0.1:8787`。
如果 Windows 浏览器连不上，把监听地址改成 0.0.0.0：`--addr 0.0.0.0`。

## 界面

```
顶栏  案件类型 · 开始录音/停止 · 导入录音 · 新开一场 · 回放条 · 计时
左栏  必问清单：顶部「这轮最该补问」2 条（带话术，点一下复制）
      下面按分组列 18 项，色块 红/黄/绿，点色块可人工纠正
中栏  实时提醒：数字确认 / 风险 / 证据固定 三类卡片，带来源 id
右栏  转写：时间 + u_ 编号，点一句跳回录音那一秒
底栏  模型 / 字数 / 覆盖统计 / 导入进度
```

## 怎么用

1. 选案件类型（劳动争议 / 民间借贷）
2. 点「开始录音」，允许麦克风 → 话筒图标变绿
3. 说话，右栏逐句出字（说完一句约 0.4 秒出整句）
4. 左栏色块实时变：金额一出现，中栏立刻弹「金额口径」提醒
5. 点「停止」。想接着录，再点「开始录音」，时间轴会接着走，不会从 0 重来

手里有录音/视频？点「导入录音」，支持 mp4 / mov / mkv / m4a / wav / mp3。
**导入会新开一场**（不会混进正在谈的场次），上传时顶部有提示、中栏有进度卡。

**正在录音时点「导入录音」**：会先把这一场停掉（录音照样存盘、时间轴保留），再让你选文件——
不会让导入和录音抢同一个 audio.wav。

导入完会自动**回放录音**，文字跟着播放进度一句句露出来（跟参考 demo 一致）。
播放结束自动显示全文；想立刻看全文，点右栏标题旁的「全部显示」。

转写本身是**整段连续**跑的，不按固定秒数切片——所以不会一坨一坨蹦，
也不会出现「一句话正好跨在切片边界上被砍成两句」。
上传后后台转写（7 分半的录音约 30 秒转完），进度在底栏。

顶栏「**历史**」列出所有场次（时间、案件、段数、时长），点一下切回去看——
导入新录音不会覆盖旧的，每一场都在 `consultations/` 里各占一个目录。

**重启服务会自动接回最近一场**（挑有转写内容的那个场次），正在谈的案子不会因为重启丢掉。

## 接口

| 方法 | 路径 | 用途 |
|---|---|---|
| WS | `/asr?samplerate=16000` | 实时转写，发 PCM16，收 `{type:partial|segment}` |
| GET | `/api/state` | 清单 + 提醒 + 统计 |
| GET | `/api/transcript` | 全部转写段 |
| GET | `/api/cases` | 案件类型与清单分组 |
| GET | `/api/audio` | 录音回放，支持 Range |
| POST | `/api/reset` | 新开一场 |
| POST | `/api/override` | 人工纠正某项状态 |
| POST | `/api/upload` | 导入录音 |
| POST | `/api/upload/cancel` | 取消导入 |

## 数据落盘

```
consultations/<日期时间>-<案件>-<序号>/
  transcript.json   转写段（带 u_ id 和时间轴）
  checklist.json    清单状态 + 证据 id
  reminders.json    提醒卡片
  audio.wav         录音（边录边写，崩溃也能播）
```

## 已知限制

- 清单判定**只靠关键词**（每项的 hints），没有模型语义判定。现在的口径：绿=至少两句不同的话命中、至少两个不同提示词、且其中一个词长度≥2；客户说「没有/记不清」的不算正面回答，最多给黄。漏判的补法：往 `data/checklists.json` 的 `hints` 里加词
- 有些提示词太通用（「电话」「记录」「公司」），单项会因此偏黄偏绿。要更准得给每项区分「强提示词 / 弱提示词」，这是下一批的事
- 提醒规则还不分案件类型：借贷里说「借了 5 万」也会问「税前还是到手」
- SenseVoice 是离线模型，**没有半句草稿**：连续说话超过 8 秒时屏幕会暂时静止（一场面谈约 5 次）
- 会后总结没做（voice-consult 里有，可直接搬）
- 历史列表能看日期、能切场次，但还不能改名、删除、按客户名搜索
- 金额目前只提示口径，**不计算**。算钱要接 voice-consult 的 `calc.py`
- 界面主要交互（展开、折叠、色块、导出）用无头 Chrome 点过；Safari / Firefox / 手机浏览器没测
